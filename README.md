# День рождения в Парке Сказка

Статический адаптивный лендинг, собранный по презентации-каталогу детских праздников Парка Сказка.

## Локальный запуск

Откройте `index.html` или запустите любой статический сервер из папки проекта.

## Структура

- `index.html` — содержание и семантическая разметка.
- `styles.css` — дизайн-система и адаптивные состояния.
- `script.js` — мобильное меню, фильтр впечатлений и выбор пакета.
- `assets/images/` — изображения, извлечённые из предоставленной презентации.
- `assets/skazka-logo.png` — ранее переданный официальный логотип Парка Сказка.

Цены и условия на странице перенесены из исходного каталога. Перед публикацией и бронированием их нужно подтвердить у отдела продаж.
